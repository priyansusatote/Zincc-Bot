# P4.0 · Run the parser outside the control plane

**Implemented** a fixed-operation worker contract. Spring sends bytes to an image ID with a fixed operation and receives a bounded JSON response. Runtime root filesystem, egress, user, resources and lifetime are constrained independently. Even a slow container has its own deadline. Confirmed no route, Docker socket, or Zincc keys in the worker. The workstation test does not establish a hostile-tenant isolation guarantee.
