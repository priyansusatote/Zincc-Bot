# P4.2 · Find a relevant private passage

**Implemented** full-text ranking, offline MiniLM vectors, and reciprocal-rank fusion. The full-text leg rewards exact words. The dense leg can connect a paraphrase to source text. Strict owner and membership checks apply before dispatch and before results leave the database. The two-page dense check placed the labeled page first for all six synthetic queries. Treat that Recall@1 result as a regression fixture. A representative held-out corpus and calibrated abstention threshold remain future evaluation work.
