# P4.4 · Preserve the source behind a chart

**Implemented** saved dashboard revisions that point back to one immutable document table. Chart and CSV run the same transformation. Revision checking detects stale edits and exports. The workbench links rows to the original page and shows measure-cell coordinates. The underlying access policy also covers derived totals and exports. A signed-in Edge run saved a North-only view, reloaded it, and verified that its 17.00 USD total and two exported source rows agreed.
