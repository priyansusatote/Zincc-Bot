# P6.2 · Qualifying a hosted runtime

**Studied and prepared for evaluation.** A container restricts processes while sharing its kernel. A microVM adds a guest kernel. Provider policy, attached credentials and reusable disks still determine which data crosses tenants. A fast create call gives no evidence about any of those controls.

The dry-run benchmark declares the exact resource, delete TTL and synthetic probes. Separate cold provisioning from subsequent command latency. Pair a failed network request with policy logs to distinguish an enforced block from an unavailable destination. The local engine cannot supply hosted benchmark evidence. Public tenant execution stays gated until the [qualification criteria](../modules/phase-six-runners.md) pass.
