# P7.4 · A smaller prompt can still produce a worse result

**Experimentally evaluated.** Three strategies processed synthetic inbox, calendar and report fixtures. Direct calls described the catalog up front. Lookup asked for a relevant schema first. The program variant also interpreted a bounded read-and-reduce plan and returned its aggregate. Every page read rechecked the grant.

Across six scripted cases per strategy, direct calls consumed 13,378 prompt characters and the program variant consumed 2,042. Both got all six answers right with the scripted planner. The live model experiments produced errors and incorrect answers, and two routes encountered rate limits. A smaller interface alone did not justify changing the serving default.

Promotion requires a full comparable cohort, correct answers and lower total tokens on a model route. The fixture comparison uses character counts and can change only its own offline selection. The qualification exercised promotion, a subsequent trial using that selection and rollback. [Results, including failed trials](../phases/p7-evaluation.md)
