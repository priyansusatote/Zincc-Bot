# Negotiating a private tool call

The briefing adapter initializes its fixed stdio server, checks the protocol and tools capability, and compares the returned input schema to the approved schema before sending selected source text. The server receives a list of bounded strings. Credentials remain in Spring.

**Implemented and tested** — incompatible revision, unexpected input schema and excessive metadata fail before private arguments are written. The browser journey exercises the actual isolated tool. Open-ended MCP discovery and customer executables need separate qualification.
