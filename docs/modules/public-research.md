# Public web research

Open **Public web research** in an authenticated workspace. Enter up to 300 characters. The default source is English Wikipedia. The request sends only the entered terms. Results include verbatim passages, requested and final article URLs, observation time, cache status and coverage. Only the research query leaves through this adapter. The account's chat history and credentials stay out of that request. Search results are transient.

The POST endpoint at `/api/workspaces/{workspaceId}/research` requires a session, current membership and CSRF token. The input fields are `query` and `fresh`. Local-only deployments suppress the UI and reject calls before search. Set `zincc.research.enabled=false` to disable it independently.

The Wikipedia adapter discovers at most six titles and reads the first three introductions. Every call goes to the fixed HTTPS MediaWiki endpoint, accepts at most 128 KiB and has a five-second deadline. HTTP redirects are refused. Wiki title redirects resolve inside that API. Four searches can run concurrently per process. The bounded public-page cache holds up to 128 titles for five minutes. Search errors return 502; page errors reduce coverage. “Fetch fresh pages” re-reads selected introductions. The source's observation time describes retrieval rather than original publication.

Run `WebResearchTest` for offline protocol tests. Set `ZINCC_WIKI_SMOKE=true` to include a real public lookup. For wider coverage, the operator can select the hosted Firecrawl v2 adapter. Set `zincc.research.provider=firecrawl`, `zincc.research.domains` to comma-separated approved public hostnames, and `FIRECRAWL_API_KEY` in the service environment. The UI names the selected provider. One search requests up to six results and up to three fresh scrapes, each with a ten-second HTTP deadline. The adapter checks requested and returned HTTPS hosts and discards out-of-scope evidence. The hosted provider controls navigation while scraping. Configure a provider-side spend cap before enabling a shared account. Local-only disables either adapter before reading credentials. The Firecrawl integration passed loopback protocol tests. Hosted account access and charges were not exercised.
