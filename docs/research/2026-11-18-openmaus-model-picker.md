# OpenMausBot model picker review

18 November 2026. Inspected selected UI, routing, discovery and driver source at [35d0442](https://github.com/milind-soni/OpenMausBot/tree/35d044295697ef2b79b889461af6902c85a1b456). This supplements the earlier desktop-control review. Evidence below is source inspection, including reading upstream tests. Live account sign-in, usage, and upstream test execution were outside this review. Reuse is design inspiration only. Upstream describes an Apache-2.0 core and a separately licensed enterprise directory. [Licensing](https://github.com/milind-soni/OpenMausBot/blob/35d044295697ef2b79b889461af6902c85a1b456/LICENSING.md)

| What the source shows | Decision for Zincc |
| --- | --- |
| The compact picker groups ready connections, offers setup for other providers, and conditionally exposes thinking controls. Conversations can follow a bot or keep their own selection. [Picker tests](https://github.com/milind-soni/OpenMausBot/blob/35d044295697ef2b79b889461af6902c85a1b456/src/components/ModelPicker.simple.test.ts) | Add a compact picker to the agent profile and conversation composer. Show the effective connection and model on the closed control. Reveal reasoning options reported for that exact combination. |
| The server can return selected conversations to their bot default. It counts busy conversations separately. [Thread-model route](https://github.com/milind-soni/OpenMausBot/blob/35d044295697ef2b79b889461af6902c85a1b456/server/routes/thread-models.ts) | Offer **Follow agent default** and **Use for this conversation**. A change affects future runs. Keep the current run's selected route and show when the change takes effect. |
| OpenCode uses a bounded ACP discovery session and extracts provider-qualified model IDs. Antigravity reads model options returned for the current Google account. Kimi also consults configured models and catalog data. [OpenCode probe](https://github.com/milind-soni/OpenMausBot/blob/35d044295697ef2b79b889461af6902c85a1b456/server/drivers/acp/opencode-probe.ts) · [Antigravity discovery](https://github.com/milind-soni/OpenMausBot/blob/35d044295697ef2b79b889461af6902c85a1b456/server/drivers/antigravity-acp.ts) · [Kimi driver](https://github.com/milind-soni/OpenMausBot/blob/35d044295697ef2b79b889461af6902c85a1b456/server/drivers/acp/kimi.ts) | Cache discovery by workspace, connection, account and runner. Mark stale or catalog-only entries. Refresh after sign-in, account changes or a model rejection. A cache entry alone never authorizes dispatch. |
| Kimi's tests expect model selection before the prompt, and suppress the prompt when the engine rejects the selection or retains the previous model. [Selection tests](https://github.com/milind-soni/OpenMausBot/blob/35d044295697ef2b79b889461af6902c85a1b456/server/drivers/acp/kimi-model-selection.test.ts) | For an explicit engine selection, compare the effective model or documented canonical alias with the requested ID before sending private task content. Where confirmation is unavailable, offer only a clearly labelled **Engine default** for that route. |

## Provider findings

| Picker entry | Proposed route and qualification |
| --- | --- |
| OpenCode | Connect the installed engine and discover models from its configured providers. OpenCode Go also offers a subscription accessed with its own key. Distinguish Go allowance, another configured API key, and any provider-side top-up setting. Qualify each supported billing route. [OpenMausBot integration](https://github.com/milind-soni/OpenMausBot/blob/35d044295697ef2b79b889461af6902c85a1b456/docs/opencode-go.md) · [OpenCode providers](https://opencode.ai/docs/providers) |
| Google Antigravity | The official CLI exposes ACP and reuses its own sign-in. Show the options returned by the selected account and runner. Validate the intended Zincc edition and use case, available models and limits on a real account. [Google ACP documentation](https://antigravity.google/docs/cli/acp) |
| Claude Code | Retain P9.8. An eligible user signs in through the unmodified Claude Code binary under Anthropic’s conditions. A direct model API connection is separately configured and billed. Keep Claude credentials inside the official flow. [Anthropic’s product integration and authentication conditions](https://code.claude.com/docs/en/legal-and-compliance) |
| Kimi Code | The CLI supports provider-owned login and ACP. Distinguish a Kimi Code account, a Kimi Platform API key, and a Kimi model served through OpenCode Go. Qualify account entitlement and model confirmation independently. [Kimi setup](https://moonshotai.github.io/kimi-code/en/guides/getting-started.html) · [Kimi ACP](https://moonshotai.github.io/kimi-cli/en/reference/kimi-acp.html) |

An additional product idea is to preview the impact of changing an agent default: show which conversations follow it, which have overrides, and which scheduled routines would use the new connection or billing source. Require explicit confirmation for a billing-source change. The scheduled-routine preview is a Zincc proposal extrapolated from the upstream conversation inheritance behavior.
